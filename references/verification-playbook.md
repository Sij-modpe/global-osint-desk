# 核验手册

> **目录**：一、五问法 ｜ 二、溯源链与循环引用 ｜ 三、地理定位 ｜ 四、时间定位 ｜ 五、影像取证 ｜ 六、账号溯源 ｜ 七、矛盾处理 ｜ 八、拒绝清单 ｜ 九、核验记录表

核验的目标不是"证明它是真的"，而是**判断它值多少**，以及**在什么条件下它会变成假的**。默认怀疑，逐层放行。

---

## 一、五问法（任何一条信息，先过这五问）

1. **谁说的**——具体到机构与个人，不接受"消息人士"。
2. **何时说的**——发布时间 vs 事件时间。旧闻新炒是最常见的操弄手法。
3. **在哪说的**——原始平台 vs 转载平台。截图不算出处。
4. **原话是什么**——找到原文原句，注意引语被截断、修饰语被删、条件句被抹平。
5. **最早出处在哪**——沿引用链回溯到第一手。找不到第一手，就是"来源不明"。

五问缺三项以上，直接降为 `x3` 以下，进待核栏。

## 二、溯源链与循环引用（OSINT 第一大坑）

### 2.1 循环引用的典型形态

```
机构 A 发布报告 → 媒体 B 报道"据 A 报告" → 媒体 C 报道"据 B 报道"
→ 机构 A 在更新版中引用"C 报道称" → 读者看到"A、B、C 三家均确认"
```

独立性在此处**完全不存在**，但表面上有三家。这类错误在快速新闻周期里极为普遍，且极难被读者察觉。

### 2.2 识别操作

1. **锁定核心句**：取报道中最关键的那句断言（通常是数字或引语），加引号精确搜索。
2. **看时间戳**：按时间排序，找最早一条。所有晚于它的，默认是下游。
3. **搜"据…报道/according to/citing"**：文内出现这类词，说明作者自己也没拿到一手。
4. **比对措辞**：若两家媒体的句子**逐字相同**，必为同源（共同通讯社稿或互相抄）。
5. **查数字的原始出处**：所有引用同一数字的报道，最终应指向同一份统计。若指不到，该数字来源不明。
6. **看是否有反向引用**：一手机构在后续文件中引用媒体报道，是循环引用闭合的标志。

### 2.3 独立性判定表

| 情形 | 计为独立来源数 |
|---|---|
| 两家媒体，同一通讯社稿 | **1** |
| 两家媒体，各自独立采访，但引用同一官员的话 | **1**（共同信源） |
| 官方发布 + 媒体转述官方 | **1** |
| 官方发布 + 独立机构实地核实 | **2** |
| 官方发布 + 卫星影像印证 | **2** |
| 三家媒体均引"不愿具名的西方官员" | **1**（且来源不可评估，`F`） |

**规则**：报告中的"N 个独立来源"必须按本表计算。虚报独立性是比造假更常见的职业性失误。

## 三、地理定位（GEOINT-lite）

对图片/视频声称地点的验证，按以下顺序：

1. **可读文字**：路牌、店招、车牌、广告、涂鸦。语言与字体即缩小范围的第一线索。
2. **地形与地貌**：山脊线走向、河流弯曲、海岸形状。与地形图/卫星图比对标定。
3. **建成环境**：建筑风格、屋顶材料、窗型、围墙高度、电线杆形制、路面材质与标线。
4. **植被**：树种、密度、季节状态（可与影像日期交叉判断）。
5. **关键基础设施**：变电站、水塔、烟囱、桥梁结构、基站天线朝向。
6. **太阳与阴影**：用 SunCalc 类工具，输入候选地点与日期，比对影子方向与长度。**影子是最硬的物理证据之一**，伪造成本高。
7. **卫星影像比对**：候选地点在影像日期前后的建筑增减、道路变化。新出现的设施本身就是情报。
8. **街景与用户照片**：在候选点周边做全景比对。

**结论表述**：写"与 X 地 Y 位置高度吻合（高置信度）"或"不能定位，仅可判断位于 Z 国境内（低置信度）"。**不要因为"看起来像"就宣布定位成功**。

## 四、时间定位

- **影像内线索**：天气（比对历史气象记录）、植被季相、积雪、积水、影子长度、屏幕/告示牌上的日期、商品包装版本、车型年款。
- **上传时间 ≠ 拍摄时间**：平台时间戳可被修改，且存在大量"旧片新发"。
- **首次出现时间**：用反向图搜与关键词检索找该影像最早的公开出现时间，这是"不早于"的硬边界。
- **连续影像的时序**：同一场景的多张影像按光照/人流排序，可重建事件序列。

## 五、影像与音视频取证

### 5.1 反向检索

Google Lens、Yandex Images（对同一场景不同角度、人脸、地点识别较强）、Bing Visual Search、TinEye（擅长找最早出现版本）。多引擎并行，结果常互补。

### 5.2 元数据

- EXIF 可被轻易清除或伪造，**只能作为辅助**，不能作为定论。
- 文件创建时间、修改软件痕迹、缩略图不一致，可提示二次编辑。
- 截图会丢失全部元数据——要求对方提供原文件。

### 5.3 合成与篡改识别

- **视觉异常**：手指数量与关节、牙齿排列、耳廓结构、发丝与背景交界、眼镜反光一致性、背景直线的扭曲、物体边缘的模糊圈、光照方向不一致（同场景两个光源方向）。
- **时序异常**：口型与音频不同步、眨眼频率过低、头部转动时的边缘抖动、饰品/衣领在帧间跳变。
- **物理异常**：影子与光源不符、反射中缺失应有物体、水面/镜面无正确倒影。
- **文本区域**：招牌、屏幕、文档上的文字常最先崩坏（字形扭曲、字母粘连）。

**必须说明的限制**：目前**没有任何自动化工具能可靠判定深度伪造**，检测器对新一代生成模型普遍失效，且存在系统性偏向。因此：

- 不得仅凭"检测工具判定为真/假"下结论。
- 结论应表述为"存在 N 处与真实拍摄不一致的痕迹，评估为高度可能存在合成（中等置信度）"，并附具体痕迹位置。
- 反向推：**能定位、能定时、有独立第二机位**的影像，其真实性远比"检测通过"可靠。

### 5.4 音频

背景声（语言、方言、广播、警笛型号、鸟鸣）可反推地点与时间；剪辑痕迹看呼吸节奏与房间混响的断裂。

## 六、账号与网络溯源

| 检查项 | 含义 |
|---|---|
| 账号创建时间 | 新建账号 + 高政治性内容 = 高风险 |
| 改名历史 | 频繁改名（尤其改向不同议题）提示账号被转用或买卖 |
| 粉丝/关注结构 | 粉丝与关注严重失衡、粉丝以新建账号为主，提示非自然增长 |
| 发帖节律 | 24 小时不间断发帖提示多人运营；与某地时区严格一致提示运营位置 |
| 语言指纹 | 用词习惯、标点、错别字模式、翻译腔（机翻痕迹是重要指标） |
| 跨平台复用 | 同一头像/简介/用户名在其他平台的历史内容，常暴露真实活动轨迹 |
| 内容原创性 | 全是转发、无原创观察，价值极低 |

**边界**：以上仅用于**机构、官方账号、疑似影响力行动网络**的评估。**不得对普通私人个体做画像**（见 `tradecraft-and-ethics.md`）。

网络层面：域名注册时间与注册商、托管 IP 归属、证书透明日志中的子域、页面模板复用（同一套模板批量建站是影响力行动的典型特征）。

## 七、矛盾处理

遇到两个可靠来源说法冲突时：

1. **不要折中**。取中间值是最没有信息量的处理。
2. **先查口径**：统计范围、时间口径、定义差异，常能解释大部分"冲突"。
3. **再查利益**：谁从这个数字里获益？
4. **再看时点**：是否一方引用的是旧数据？
5. **若确实冲突**：并列呈现，标注各自评级，写明"差异原因未明，倾向 X（中等置信度）"，并把"查明差异原因"列入待查清单。

**差异本身常常是最好的情报**：两方对同一事实的不同表述，暴露的是各自的立场、能力或遮掩重点。

## 八、拒绝清单（命中即不得写入结论）

- 无法回溯到任何一手出处的
- 仅有一个来源且该来源为 `D`/`E`/`F` 的
- 仅有匿名单一信源支撑的重大指控
- 利益直接相关方的单方指控（可报道其"指控"这一事实，不可报道"指控内容为真"）
- 截图、录屏、二次转述作为唯一证据的
- 时间、地点、人物三要素中任一无法确认，却用于支撑因果判断的
- 由 AI 生成嫌疑高且无第二机位/无地理定位支撑的

## 九、核验记录表（每条关键信息填一行，随报告归档）

| 字段 | 填写要求 |
|---|---|
| 信息编号 | 与事件台账一致 |
| 断言原句 | 保留原语种 + 中译 |
| 最早出处 | URL + 发布方 + 发布日 |
| 抓取日 | 实际访问日期 |
| 来源评级 | A–F |
| 信息评级 | 1–6 |
| 独立印证数 | 按第二节判定表计算 |
| 核验手段 | 反向图搜/地理定位/官方文件比对/… |
| 未解疑点 | 明确写出 |
| 结论 | 采信 / 部分采信 / 存疑 / 不采信 |
