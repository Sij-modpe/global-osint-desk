# 情报科学与 OSINT 方法基线

本文件是作业的"度量衡"。凡涉及评级、置信度、假设检验、归因，一律以本文件为准，不得临场自创标准。

> 性质说明：NATO 来源评级体系、美国情报界 ICD 203 概率语言属**成文规范**；结构化分析技术源自 Heuer 的认知心理学传统与后续官方 tradecraft 手册；"归因六检"等属**实务综合**，非任何官方条文的原文照搬。文中已分别标注，勿混为一是。

---

## 一、从数据到情报：DIKW 与情报循环

数据 → 信息 → 知识 → 情报。分界线在**是否服务于特定决策**。一条事实无论多准确，若与决策问题无关，就不是情报，是噪音。

情报循环六环节（本技能对应五阶段）：

| 环节 | 本技能阶段 | 失败后果 |
|---|---|---|
| 需求与指导 | 阶段 0 | 全链条方向错误，做得越扎实越无用 |
| 采集规划 | 阶段 1 | 源结构单一，必然偏见 |
| 采集 | 阶段 2 | 拿不到原文，只能转述别人的转述 |
| 处理与加工 | 阶段 3 | 重复计数、循环引用被当成印证 |
| 分析与生产 | 阶段 4 | 输出复述而非判断 |
| 分发与反馈 | 阶段 5 | 无人使用，且无迭代修正 |

循环是闭环：分发后的反馈必须回流修正 PIR。一次性作业等于放弃了自我校正能力。

## 二、需求管理：PIR / EEI / 情报缺口

**PIR（Priority Intelligence Requirements，优先情报需求）**
针对决策者已知的决策点，提出的、可被证实或证伪的关键问题。写法要求：

- 祈使句，指向未来或有争议的现状："评估 X 国在 Q4 是否会将 Y 类物项纳入出口许可"。
- 一条 PIR 只问一件事。含"和/或"的句子必须拆开。
- 必须可被证伪。不可证伪的（"评估局势走向"）不是 PIR，是愿望。

**EEI（Essential Elements of Information，基本要素信息）**
把每条 PIR 拆成若干"查得到就能推进判断"的具体事实点。EEI 是采集的清单，PIR 是判断的靶子。没有 EEI 的 PIR 落不了地。

**情报缺口（Intelligence Gaps）**
三类分别对待：
1. **已知未知**——知道该查什么但查不到。写进报告"待查清单"，注明需要什么手段才能补。
2. **未知未知**——不知道存在的信息。只能靠广泛扫描与红队审视降低风险，不能消除。
3. **被刻意隐藏**——对方主动遮蔽。评估其遮蔽行为本身即为情报（遮什么，说明在意什么）。

**需求优先级判定**：影响 × 紧迫性 × 可获取性。可获取性极低而影响极大的项，不应删除，应单列为"关键不确定性"。

## 三、来源可靠性 × 信息可信度（Admiralty / NATO 双轴评级）

### 3.1 轴一：来源可靠性（Source Reliability）

| 级 | 定义 |
|---|---|
| **A** | 完全可靠：历史记录一贯准确，无偏向性失真 |
| **B** | 通常可靠：多数准确，偶有差错 |
| **C** | 尚可可靠：有准确记录，但也有明显失误 |
| **D** | 通常不可靠：历史记录不可信，需大幅折扣 |
| **E** | 不可靠：已知有系统性失真、宣传或造假记录 |
| **F** | 无法判断：新源、匿名源、无历史可考 |

### 3.2 轴二：信息可信度（Information Credibility）

| 级 | 定义 |
|---|---|
| **1** | 已由其他独立来源确认 |
| **2** | 大概为真：逻辑自洽，与已知情况一致，但未独立确认 |
| **3** | 可能为真：说得通，但缺乏支撑 |
| **4** | 可疑：与其他已知信息冲突，无法解释 |
| **5** | 不可能：与确证事实矛盾，或逻辑不成立 |
| **6** | 无法判断：信息本身不完整或含义不清 |

### 3.3 使用规则

- **两轴独立打分**。A 级来源也会发出 4 级信息；E 级来源偶尔发出 1 级信息（宣传机构往往在可核查的技术细节上说真话，以换取在关键处的可信度）。不要因为讨厌来源就否定信息，也不要因为信息诱人就抬高来源。
- **打法**：先给来源定级（看历史记录，不看本条内容是否合意），再对**每条信息单独**定可信度（看本条是否被印证）。
- **"1"级门槛**：必须由**彼此独立**的来源确认。转载不算。判独立性的方法见 `verification-playbook.md`。
- **典型组合含义**：
  - `A1` 可作为判断基石。
  - `B2` 可支撑判断，但需在报告中标注未独立确认。
  - `C3` 只能作为线索，进"待核"栏。
  - `D4`/`E5` 不作为证据，但可作为"对方在说什么"的情报（研究宣传叙事时需要）。
  - 任何 `x6` 都不得引用，只能记为"信息不清，无法评估"。
- **禁止加权平均**。不存在"综合可信度 = (A+B)/2"这种东西。评级是定性的，不是打分的。

## 四、概率语言与分析置信度（ICD 203 体例）

### 4.1 概率表达（表意概率词，成文规范）

| 中文表述 | 英文对应 | 概率区间 |
|---|---|---|
| 几乎不可能 | almost no chance | 01–05% |
| 极不可能 | very unlikely | 05–20% |
| 不可能 | unlikely | 20–45% |
| 大致对半 | roughly even chance | 45–55% |
| 可能 | likely | 55–80% |
| 极可能 | very likely | 80–95% |
| 几乎确定 | almost certain | 95–99% |

使用纪律：
- 每次使用概率词，**同一份报告内必须前后一致**，不得在第二节说"可能"、第六节说"概率较大"指同一量级。
- 不给虚假精度。没有基准率支撑时，写区间不写点值。
- 概率与置信度是两件事：可以说"极可能（中等置信度）"——判断方向有把握，支撑材料不够硬。

### 4.2 分析置信度（三分级，成文规范）

| 级别 | 判定依据 |
|---|---|
| **高** | 多源独立印证；来源可靠；关键假设已检验且成立；对替代解释有充分排除 |
| **中** | 有可信来源支撑但未完全独立；存在未检验的假设；替代解释未被排除干净 |
| **低** | 来源可疑或单一；高度依赖未验证假设；信息碎片化、存在明显空白 |

置信度低不等于不说。要说，但必须**显式标注为什么低**，并写清补什么能提升。

## 五、结构化分析技术（SATs）操作要点

### 5.1 ACH 竞争假设分析（默认必做）

1. 列出 ≥3 个**互斥**假设（含"以上皆非/事件另有解释"这一兜底项）。
2. 列出关键证据与论点（每条挂评级）。
3. 建矩阵：证据 × 假设，逐格判"一致 / 不一致 / 中性"。**中性项比一致项更重要**——一致项往往对多个假设都成立，无区分力。
4. 逐假设统计"不一致"数量，取最少者。
5. 反问：该假设要成立，还需要哪些目前没有的证据？这些证据若出现会推翻什么？
6. **禁忌**：先有结论再找证据（这是动机性推理，不是 ACH）。矩阵必须在写结论之前建。

### 5.2 关键假设检验

列出"若要我这个判断成立，必须为真的前提"，每条判：有无证据支持、若不成立结论如何变化。常见盲区——把当下的延续当作常态（"过去三个月没变，所以下个月也不会变"）。

### 5.3 指标与预警（Indicators & Signposts）

为每个判断设计 3–5 个**可观测**的先行指标，要求：可被外部观察、有明确阈值、有观测渠道。写成"若出现 X，则 Y 的概率上升/下降"的形式。下一期作业时逐条回填"已出现/未出现/无数据"。这是让情报工作产生复利的唯一机制。

### 5.4 其余技术速查

| 技术 | 用途 | 触发条件 |
|---|---|---|
| Devil's Advocacy | 专设反方攻击主结论 | 结论已成型、团队共识过强 |
| Team A/Team B | 两套解释方案对抗 | 存在两个旗鼓相当的解读 |
| What-If 分析 | 假定某事件已发生，倒推条件与影响 | 低概率高影响情景 |
| High-Impact/Low-Probability | 小概率巨灾评估 | 决策不可逆、代价极高 |
| Red Team | 站在对手视角重算 | 涉及对手意图判断 |
| Outside-In | 从外部环境倒推，而非从自身出发 | 陷入内部视角时 |
| Quality of Information Check | 排查证据链的完整性与陈旧度 | 报告定稿前 |
| Alternative Futures | 构造 3–4 个未来情景 | 长期趋势判断 |

## 六、认知偏差清单（逐条自查，写下自查结论）

| 偏差 | 表现 | 对策 |
|---|---|---|
| 证实偏差 | 只找支持既有判断的材料 | ACH 矩阵；专门搜集反证 |
| 锚定 | 首个数字/首条报道定调 | 主动寻找不同量级的数据源 |
| 可得性 | 好搜到的当成重要的 | 计数：报道多≠发生多 |
| 镜像思维 | 假定对手按自己的逻辑行动 | 红队；用对方语言的一手材料 |
| 群体思维 | 多方一致就以为对 | 查独立性与同源性 |
| 满意即止 | 找到第一个能解释的说法就收工 | 强制列 ≥3 假设 |
| 叙事偏好 | 喜欢因果完整的故事 | 对"太顺"的解释加压 |
| 时间投影 | 把当下线性外推 | 找历史上的非线性转折案例 |

**"太顺"是最危险的信号。** 一个能解释所有证据的解释，通常意味着证据被裁剪过。

## 七、归因纪律（实务综合，非成文条文）

涉及"是谁干的"时，逐项过检，缺项即降级表述：

1. **动机**：有无获益逻辑？获益是否唯一指向该行为体？
2. **能力**：技术、资源、地理可达性是否具备？有无同等能力的其他行为体？
3. **手段痕迹**：手法是否与该行为体历史模式一致？一致性本身是否可被伪造（false flag）？
4. **时序**：是否与已知决策节点吻合？
5. **多源一致**：是否有彼此独立的证据链指向同一结论？
6. **替代解释排除**：至少列出并评估一个替代行为体。

表述分级：
- 六项齐备且独立 → "评估为 X 所为，极可能（高置信度）"
- 缺 1–2 项 → "评估为 X 所为，可能（中等置信度），不排除 Y"
- 缺 3 项以上 → **不做归因**。写"实施者尚不能确定"，并列出候选与各自疑点。

**铁律**：归因是情报工作中最容易被政治需求污染的一环。压力越大，越要写成条件句。

## 八、报告语言规范

| 禁用 | 替换为 |
|---|---|
| 据悉 / 有消息称 / 分析人士认为 | 具体来源 + 评级 |
| 综合多家媒体报道 | 列出 2–3 家具名来源 |
| 局势持续紧张 | 指标 + 阈值 + 时间窗 |
| 不排除 / 有可能 / 或将 | 概率词 + 置信度 |
| 显然 / 众所周知 | 删除，或给出证据 |
| 大幅 / 显著 / 严重（无基准） | 给数字与对比基期 |

**四层隔离**（排版必须分开，不得混写）：

- `【事实】` 已证实、可直接引用的
- `【推断】` 由事实经逻辑推出的
- `【评估】` 分析者的判断，含概率与置信度
- `【预测】` 指向未来，必附条件与时间窗
